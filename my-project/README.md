# My Project

This project is a serverless application that provides promotion data through an API.

## Project Structure

```
my-project
├── api
│   └── promocoes.js
├── package.json
└── README.md
```

## API

The API is located in the `api` directory. The main function is in `promocoes.js`, which returns promotion data in JSON format.

### Endpoints

- **GET /api/promocoes**: Returns a list of promotions.

## Installation

To install the necessary dependencies, run:

```
npm install
```

## Usage

To start the serverless function locally, you can use a serverless framework or deploy it to Vercel for testing.
